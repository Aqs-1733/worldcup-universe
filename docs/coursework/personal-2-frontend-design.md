# 个人作业2：Axure Web 前端设计

本作业独立提交，不出现在项目网站导航或业务页面中。设计主题为“2026 世界杯赛事中控台”，视觉规范与项目主页保持一致。

## 已完成内容

- Axure RP 11 从新建文件到交互预览、生成 HTML 的完整操作流程；
- 主页高保真页面结构、组件命名、尺寸、配色和响应式规格；
- 深色/浅色切换、比赛详情弹层、平滑滚动、卡片反馈等交互；
- 前台模板与 Yii2 后台模板选型说明；
- 可离线运行的交互参考原型；
- 课程提交版 Word 报告与压缩包。
