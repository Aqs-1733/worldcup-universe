# 团队作业2：设计文档

## 1. 设计目标

项目主题为“体育主题——2026 世界杯”，系统面向球迷和管理员，提供赛事、球队、球员、新闻、偏好、留言、智能解说和后台数据维护功能。

## 2. 前台页面设计

- 首页 `/`：赛事中控台、赛程、晋级关系、数据图形、球队、球员、团队展示、后台发布内容。
- 赛程 `/worldcup`：按 MySQL 比赛数据展示赛程、比分、未开始状态和积分榜。
- 球队 `/teams`、球员 `/players`：支持搜索，展示国旗、中文名、原名和核心信息。
- 新闻 `/news`：多来源抓取、中文标题和摘要、多标签分类、来源链接。
- 球迷空间 `/fan-space`：偏好设置、留言。
- 智能解说 `/commentary`：文本创作、语气自定义、球队自定义、勾选后生成图片。
- 课程个人/团队作业：只在 `docs/` 目录按阶段留存，不进入网站导航和页面。

## 3. 后台页面设计

后台统一入口 `/admin`，采用表驱动 CRUD：团队成员、球队、球员、赛程、新闻、发布内容、留言、国家资料、来源文件、校验结果等。

## 4. 数据库设计

数据库使用 MySQL，核心表包含：用户、角色、团队成员、球队、球员、教练、场馆、比赛、比赛统计、阵容、事件、积分、新闻源、新闻、标签、留言、偏好、后台发布、智能生成记录、国家资料、来源文件、来源记录、数据质量检查等，超过 10 张表。

## 5. 交互与动效

使用深色/浅色主题切换、滚动 reveal 动效、世界杯草坪背景、国旗图片、积分动态条形图、晋级图节点和新闻滚动条，满足“动态页面展示”加分方向。
