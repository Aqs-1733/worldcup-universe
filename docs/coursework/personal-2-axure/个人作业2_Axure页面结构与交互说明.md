# 个人作业二 Axure 前端设计完整流程

## 作业目标

使用 Axure RP 11 设计“世界杯赛事中控台”首页高保真原型，并为团队确定前台与后台界面模板。原型不另起视觉体系，颜色、圆角、卡片、按钮和动效全部对齐项目现有主页。

## 设计依据

- 页面名称：世界杯赛事中控台首页
- 设计尺寸：桌面端 1440 像素宽，主要内容区 1220 像素宽
- 响应式视图：Desktop 1440、Tablet 960、Mobile 390
- 深色主背景：`#090D23`
- 次级背景：`#121936`
- 面板背景：`#0F1730`，透明度约 86%
- 主文字：`#F5F7FF`
- 次文字：`#AEB8D6`
- 主蓝：`#4F7CFF`
- 金色强调：`#FFD166`
- 青色：`#38BDF8`
- 紫色：`#A78BFA`
- 字体：Microsoft YaHei / PingFang SC
- 圆角：按钮 9 像素，卡片 14 至 24 像素

## 信息架构

1. 顶部导航：品牌、首页、赛程、球队、球员、新闻、国家探索、主题切换、登录注册。
2. 首屏：标题、项目说明、球队球员赛程新闻四项统计、主要操作按钮。
3. 晋级关系：四条淘汰赛卡片，点击进入单场详情。
4. 滚动新闻：连续横向滚动的新闻摘要。
5. 数据主体：近期赛程与积分趋势图。
6. 功能入口：球队档案、球员库、新闻中心、智能解说。
7. 国家文化：球队国家、首都、大洲与旅行文化入口。
8. 比赛弹窗：比分、阵容、事件和技术统计的详情容器。

## Axure RP 11 搭建流程

### 一 新建项目与页面

1. 打开 Axure RP 11，选择 New File。
2. 将文件保存为 `作业2_世界杯赛事中控台.rp`。
3. 将 Page 1 重命名为 `P_Home_世界杯赛事中控台`。
4. 新建页面 `P_FrontTemplate_前台模板说明` 与 `P_AdminTemplate_后台模板说明`。
5. 新建三个自适应视图：Desktop 1440、Tablet 960、Mobile 390。

### 二 建立样式变量

在样式管理器中创建颜色样式 `C_BG`、`C_PANEL`、`C_TEXT`、`C_MUTED`、`C_BLUE`、`C_GOLD`、`C_CYAN`、`C_VIOLET`，再建立标题、正文、说明文字和数字四类文本样式。所有面板只引用这些样式，不逐个随意改色。

### 三 制作顶部导航母版

1. 新建母版 `M_Header`，尺寸 1440×72。
2. 左侧放置奖杯图标和 `worldcup-universe` 品牌文字。
3. 中间使用中继器 `REP_Nav`，写入首页、赛程、球队、球员、新闻、国家探索。
4. 右侧放置动态面板 `DP_Theme`、登录按钮和注册按钮。
5. 设置母版固定到浏览器顶部，背景采用深色半透明，底部增加 1 像素浅色描边。
6. 为导航项增加 MouseEnter 样式：文字改为金色，描边改为金色 48% 透明。

### 四 制作首屏与统计卡

1. 创建组合 `G_Hero`，采用左右两列布局。
2. 左侧矩形 `R_HeroPanel` 设置 24 像素圆角和蓝紫色柔光阴影。
3. 添加英文标签、两行主标题、说明文字与两个按钮。
4. 使用中继器 `REP_Stats` 创建 48、1248、104、32 四张统计卡。
5. 右侧创建晋级关系面板，使用中继器 `REP_Bracket` 显示球队、比分和状态。
6. 设置 OnPageLoad：首屏从 Y+16、透明度 0 过渡到原位和 100%。

### 五 制作新闻与数据面板

1. 使用动态面板 `DP_Ticker` 制作新闻滚动条，内部文本每 18 秒向左移动后回到初始位置。
2. 使用中继器 `REP_Matches` 建立近期赛程，每行包含时间、主队、比分、客队、阶段。
3. 使用中继器 `REP_Bars` 建立积分趋势，每条宽度根据 points 字段换算。
4. OnLoad 时先设置条形宽度为 0，再使用 1000 毫秒 ease-out 增长到数据宽度。

### 六 制作模块卡片与国家卡片

1. `REP_Modules` 使用四列布局，卡片包含序号、标题和说明。
2. MouseEnter 时将当前项上移 5 像素并加强紫色描边；MouseOut 还原。
3. `REP_Countries` 使用国旗、国家中英文名、首都和大洲字段。
4. 点击国家卡片时跳转到国家探索页；悬停时蓝色描边高亮。

### 七 制作比赛详情动态面板

1. 创建动态面板 `DP_MatchDetail`，默认隐藏。
2. 面板包含遮罩、比分标题、比赛说明、关闭按钮和四个详情标签。
3. 点击任意比赛行时设置标题文本并显示面板，使用 250 毫秒淡入。
4. 点击关闭按钮时隐藏面板，使用 200 毫秒淡出。

### 八 深浅色主题

1. `DP_Theme` 建立 Dark 与 Light 两个状态。
2. 建立全局变量 `Theme`，默认值 `dark`。
3. 点击主题按钮时切换面板状态，并批量应用对应颜色样式。
4. 深浅色均保持同一信息层级，只改变背景、面板、文字与描边色。

### 九 响应式适配

- Tablet 960：首屏和数据面板改为单列，模块卡和国家卡改为两列。
- Mobile 390：主内容边距 8 像素，统计卡两列，模块与国家卡单列，隐藏登录注册文字按钮，仅保留主题按钮。
- 所有视图保持 44 像素以上的可点击区域。

### 十 预览与导出

1. 按 F5 预览 Desktop 视图。
2. 依次验证主题切换、导航悬停、赛程滚动、比赛弹窗、新闻滚动和图表动画。
3. 切换 Tablet 与 Mobile 视图，检查元素是否溢出。
4. 选择 Publish，生成本地 HTML 预览。
5. 保存 `.rp` 源文件，并将报告、源文件、预览和截图放入同一压缩包。

## 提交前检查

- 原型颜色与项目主页一致。
- 页面使用统一样式，不存在随意添加的绿色主题。
- 主题切换、比赛详情、滚动定位、悬停状态均可演示。
- 提交文档包含过程截图、最终截图、交互表和模板选型。
- 压缩包命名为 `作业2(学号_姓名).zip`。
