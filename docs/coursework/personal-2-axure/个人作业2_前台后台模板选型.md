# 个人作业二 前台与后台模板选型

## 前台模板

选择“世界杯数据中控台”自研高保真模板。布局采用 1220 像素内容区、卡片式数据面板、CSS Grid 双列首屏与统一的蓝金视觉体系。该模板直接继承项目主页的深浅色配色、圆角、按钮和动效，因此原型与成品不会出现两套风格。

前台模板包括首页、赛程树状图、球队、球员、新闻、国家探索、搜索和智能解说等页面框架。桌面端、平板端、移动端共用同一套组件和颜色变量。

## 后台模板

选择“Yii2 数据管理后台”模板。后台使用左侧导航、顶部状态栏、数据统计卡、筛选工具栏、CRUD 表格和编辑表单。后端技术与项目保持一致，为 PHP、Yii2 与 MySQL。

后台核心模块包括球队管理、球员管理、赛程管理、新闻发布、国家资料管理、留言管理、数据来源管理和用户管理。列表页强调可检索和可维护，不复制前台的大面积动画，但继续使用蓝金配色和同一套按钮样式。

## 选型结论

前台负责展示、浏览和互动，后台负责结构化数据维护。两者共享颜色、字体、圆角和状态规范，同时根据使用场景保留不同的信息密度。该方案与现有项目实现一致，也满足团队作业中前台展示和后台编辑发布的要求。
