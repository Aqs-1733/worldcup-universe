# 个人作业3：开源建站工具初试证据模板与软件指导

> 单独提交，不放进网站页面。这个作业是 WordPress 实验，不要把 WordPress 混进 PHP + MySQL 大作业源码。

## 需要的软件

1. XAMPP：`https://www.apachefriends.org/`
2. WordPress：`https://wordpress.org/download/`
3. 浏览器：Chrome 或 Edge。

## 安装步骤

1. 安装 XAMPP。
2. 打开 XAMPP Control Panel，启动 Apache 和 MySQL。
3. 下载 WordPress 压缩包。
4. 解压到 `D:\XAMPP\htdocs\wordpress`。
5. 打开 `http://127.0.0.1/phpmyadmin`，新建数据库，例如 `wp_homework`。
6. 打开 `http://127.0.0.1/wordpress`，按安装向导填写数据库名、用户名和密码。
7. 进入 WordPress 后台，选择主题，修改首页标题、图片和布局。
8. 截图：XAMPP 启动、数据库、WordPress 安装页、后台、最终页面。
