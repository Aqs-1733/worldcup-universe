## 缓存与复核

- `public/assets/media/team-photos/manifest.json`：48 队逐队年份、来源网址、实际图片网址、图注、日期、摄影署名、授权状态、尺寸、文件字节数及 SHA256。
- `public/assets/media/team-photos/evidence/{CODE}.source.txt`：原站响应或明确标识的出版方／摄影师 API 元数据摘录；每项清单记录来源证据的 SHA256、字节数和 required_markers。摘录不是伪称整页 HTML。
- `public/assets/media/team-photos/visual-review.json`：48 张实际本地图的独立视觉核对与同文件 SHA256。
- 公开预览的水印、摄影署名均原样保留。所有本地图是原始下载响应字节；页面按容器缩放／裁切，不涂抹水印，不伪称新增开放转载许可。3 张 CC 图片的原摄影师与许可链接在 `/credits` 列出。
- `scripts/fetch_team_photos.py` 默认离线验证全部 48 队，`--refresh` 重取全部已记录图片网址，`--team CODE --refresh` 只重取一队。响应变化只放入独立候选目录，旧审核图保持不变，须重新视觉核验后发布。
- `tests/team_photo_ui.py` 逐页检查两页 48 个球队卡片、48 个球队详情以及 48 张 HTTP 返回图片的哈希；不是仅检查清单数量。

48 张图像共 **19,814,231 字节**。球队列表、首页球队卡片和详情封面均通过 TeamPhoto 读取同一份清单；球员个人照片仅用于球员资料和阵容卡片。
