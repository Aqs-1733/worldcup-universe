# 个人作业2：Web 前端设计证据模板与软件指导

> 单独提交，不放进网站页面。后续按个人学号姓名补原型截图并打包。

## 需要的软件

首选：Axure RP。官方入口：`https://www.axure.com/download`。

如果临时装不上，也可以用在线原型工具 Figma，但老师点名 Axure 时优先用 Axure。

## 下载与安装 Axure RP

1. 打开 `https://www.axure.com/download`。
2. 选择 Windows 版下载。
3. 安装后新建项目。
4. 画一个本项目相关页面，例如“世界杯国家探索页”或“新闻中心页”。
5. 导出/截图页面原型，放入个人作业文档。

## 页面设计建议

可设计“国家探索页”：

- 顶部：世界杯国家文化旅行地图。
- 主办城市卡片：城市、场馆、国家。
- 国家卡片：国旗、首都、语言、货币、球队。
- 交互：深色/浅色模式切换、卡片悬停、筛选按钮。

## 团队模板选型说明

- 前台模板：世界杯视觉主题 + 卡片式信息流 + 动态图形。
- 后台模板：表格 CRUD 管理界面，方便维护球队、球员、新闻、留言和数据来源。
