const NativeBridge = (function() {
    const Platform = {
        iOS: !!(window.webkit && window.webkit.messageHandlers),
        Android: typeof Android !== 'undefined',
        get current() {
            if (this.iOS) return 'iOS';
            if (this.Android) return 'Android';
            return 'Browser';
        },
        get isNative() {
            return this.iOS || this.Android;
        }
    };
    function sendToNative(handlerName, data) {
        const dataString = String(data);
        if (Platform.iOS) {
            const handler = window.webkit.messageHandlers[handlerName];
            if (handler) {
                handler.postMessage(dataString);
                return true;
            }
        } else if (Platform.Android) {
            const method = Android[handlerName];
            if (typeof method === 'function') {
                method.call(Android, dataString);
                return true;
            }
        }
        return false;
    }
    return {
        platform: Platform,
        playVideo: function(id) {
            if (!sendToNative('playVideo', String(id))) {
                console.log('[NativeBridge] playVideo not available - running in browser');
            }
        },
        playPlaylist: function(id) {
            if (!sendToNative('playPlaylist', String(id))) {
                console.log('[NativeBridge] playPlaylist not available - running in browser');
            }
        }
    };
})();
</script>

                <div class="rte-content rte-content--lead">
        <h2>The Three Lions wear the Marks &amp; Spencers x England edit ahead of this summer's tournament</h2>
    </div>
    <div class="rte-content rte-content--normal">
        <p><strong>A partnership rooted in shared pride, heritage and a belief in football&rsquo;s power to bring people together.</strong></p>
<p>First established in 2007, when M&amp;S became the official suit supplier to our England senior men&rsquo;s team, its long-standing relationship with the FA enters a new chapter in 2026.</p>
<p>As official formalwear partner, M&amp;S introduces the M&amp;S x England edit - a modern, modular wardrobe designed for life off the pitch.</p>
<p>Defined by elevated, tailored style, the collection blends signature British design with purpose-built functionality, created for the global stage. Built for movement, presence and impact, the wardrobe is designed for life on the move, reinforcing that style and function transcend the game.</p>
<p>Football is the most-watched sport among M&amp;S customers, with 75 per cent* actively following the game, underscoring a strong audience connection. With 77 per cent of men and 49 per cent* of women planning to watch this summer&rsquo;s tournament, the partnership reflects football&rsquo;s unmatched scale and appeal.</p>
    </div>
<figure class="image-with-caption">
        <picture>
            <source media="(max-width: 800px)" srcset="https://cdn.englandfootball.com/-/media/EnglandFootball/Article/england/mens-senior-team/2026/June/Team-photo-485-20261106.png?h=656&amp;iar=0&amp;w=485&amp;rev=51cf9223bc36430ca6d7da8fb0903289&amp;hash=94DA6794A57D0BC075E87322AB8A64CA">
            <source media="(min-width: 801px)" srcset="https://cdn.englandfootball.com/-/media/EnglandFootball/Article/england/mens-senior-team/2026/June/Team-photo-952-20261106.png?h=536&amp;iar=0&amp;w=952&amp;rev=375f5b5f1047445dae97e07167343bcd&amp;hash=DE6408E6502C7D30ECBA62FEC861641A">
            <img alt="M&amp;S are the official formalwear partner" loading="lazy" src="https://cdn.englandfootball.com/-/jssmedia/EnglandFootball/Article/england/mens-senior-team/2026/June/Team-photo-952-20261106.png?h=536&amp;iar=0&amp;w=952&amp;rev=375f5b5f1047445dae97e07167343bcd&amp;hash=DE6408E6502C7D30ECBA62FEC861641A" alt="The England men&#x27;s senior team pose for the official M&amp;S team photo ahead of the World Cup" />
        </picture>
        <figcaption>M&amp;S are the official formalwear partner</figcaption>
</figure>

    <div class="rte-content rte-content--normal">
        <p>With a clear passion for football among M&amp;S customers, and a new generation of inspiring role models across the England teams, the partnership celebrates individuality and the collection is designed to bridge the gap between players and customers.<br>
<br>
Mitch Hughes, M&amp;S director of menswear, said: “Our long-standing partnership with the FA continues to evolve, and this collection starts a new chapter in our approach to modern formalwear for the England senior men’s team.<br>
<br>
“Designed as a refined 12-piece edit, it balances elevated tailoring with versatile staples that move seamlessly beyond the pitch. Ease and functionality remain central, with technical details including bi-stretch fabrication for comfort - great for travelling - alongside breathable and storm-wear finishes, suited to unpredictable weather conditions.<br>
<br>
“This season the focus has been on creating a flexible wardrobe that gives players the freedom to express their individual style while still delivering a strong, cohesive look"<br>
<br>
FA commercial director, James Gray, added: “Our partnership with M&amp;S, established in 2007, continues to reflect a shared commitment to football and to England supporters.<br>
<br>
“This next phase builds on that long-standing relationship and supports how the England men’s team is represented on the global stage. The collection has been developed with the squad in mind, and we expect it to be positively received by both players and supporters.”</p>
