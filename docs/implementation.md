# 团队作业3：实现文档

## 1. 架构实现

- `public/index.php`：单入口路由。
- `app/Core`：环境变量、PDO 数据库、路由、认证、CSRF、视图渲染。
- `app/Controllers`：页面、登录注册、后台控制器。
- `app/Repositories/AppRepository.php`：MySQL 查询和后台保存。
- `app/Services`：新闻同步、世界杯数据同步、ARK AI 调用。
- `views`：PHP 模板页面。
- `scripts`：安装、数据导入、新闻刷新、翻译补齐脚本。

## 2. 关键功能

- 账号密码注册登录，用户名与邮箱唯一校验。
- 首次问卷可填写或跳过，支持球队、球员、多选屏蔽和推送偏好。
- 世界杯数据来自采集包和网络来源，导入 MySQL 后展示。
- 球员按知名度、出场、进球排序，保留中文名与原名。
- 新闻通过 RSS 联网抓取，多标签分类，抓取时尝试中文翻译和归纳，保留原文与来源。
- ARK AI 创作支持自定义语气、球队和图片生成勾选开关。
- 后台可维护团队、个人信息、发布内容、留言和数据。
- `/coursework` 页面保留老师阶段要求和完成映射。

## 3. 数据真实性

导入脚本会写入 `source_files`、`source_records` 和 `data_quality_checks`，用于记录来源文件、原始记录和校验结果；找不到的数据不造假。
